Create a production shot plan optimized for MiniMax H3 Ref2VA.

The generator supports:
- up to 9 independent reference images in one H3 scene chain
- one primary reference video per scene chain
- one primary voice-reference audio lane per scene chain
- 24 fps
- 960x544 base generation, later delivered at 1280x720

Do NOT describe a reference image as the literal opening frame. References are identity/appearance conditioning.

For every shot return:
- duration_seconds (the application will normalize to the H3 scene-chain frame count)
- characters
- speaking_characters
- speech_text
- location
- action
- camera_shot
- camera_movement
- lighting
- mood
- visual_prompt
- negative_prompt
- continuity_notes
- seed

Reference instructions:
- Keep visual identity in the reference media and let the story control clothing, environment and action.
- Mention each relevant character by name.
- Do not invent clothing from the reference image when the story specifies different clothing.
- Do not invent the reference background as the scene background.
- Make camera and environment explicit.
- When dialogue exists, identify exactly one primary speaking character for the voice reference lane.
- Do not put two different shots into one visual_prompt. Each shot is separated by the production system.
- The system may include independent reference-image binding text such as:
  "<Picture 1>, <Picture 2> are reference images of CHARACTER_A."
- Never ask for a composite reference image.

Return ONLY JSON:

      "camera_shot": "Camera framing.",
      "camera_movement": "Camera movement.",

      "mood": "Mood.",
      "visual_prompt": "Complete H3 visual prompt.",
      "negative_prompt": "Undesired visual/audio qualities.",
      "continuity_notes": "Continuity from the previous shot.",
      "seed": null
    }
  ]
}
